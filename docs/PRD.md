# Aarozi Healthcare - Product Requirements

## Product shell
Single login, common top search, common navigation, unified patient context and configurable module menu.

## Core workflows
1. Patient registration
2. Order + referral selection
3. Pricing/discount resolution
4. Billing + payment
5. Sample collection + barcode
6. Analyzer/manual result entry
7. Verification/approval
8. Report generation + delivery
9. Referral commission ledger
10. Blood bank donor/component/cross-match/issue

## Configuration
Tenant admin can enable modules, assign roles, define branch/department scope, manage test master, pricing, referral rules and report templates.
