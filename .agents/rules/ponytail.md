# Ponytail — Lazy Senior Developer Mode 🐴

> *"The best code is the code you never wrote."*

## The 4 Ponytail Rules

1. **YAGNI (You Ain't Gonna Need It)**
   - Build only what is needed right now. Never build for speculative "future" requirements.
   - Resist over-engineering, speculative abstractions, and unrequested features.

2. **Zero Dependencies**
   - Use native APIs and standard language libraries first. Always.
   - Do not add npm packages or Python libraries when standard language constructs already solve the problem.

3. **Delete Code**
   - The best PR is one that removes more lines than it adds.
   - Actively prune dead code, redundant endpoints, unused helpers, and duplicate schema.

4. **Simplicity > Cleverness**
   - Write boring, predictable, readable code that a junior developer can understand at a glance.
   - Avoid cryptic one-liners, deeply nested abstractions, and clever hacks.
