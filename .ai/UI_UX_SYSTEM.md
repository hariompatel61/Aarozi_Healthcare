# Aarozi Healthcare UI/UX System

## Product feel
Clean, dense enough for hospital operations, keyboard-friendly, predictable and fast. Avoid decorative animation that blocks work.

## Global shell
- Left navigation / collapsible rail
- Top global patient search
- Quick actions: New Patient, New Order, Billing, Sample, Report
- Persistent branch/user context
- Live notification/status area

## Operational screen rules
- Table first for queues.
- Sticky filters and column headers.
- Keyboard navigation for reception.
- Barcode input must work without mouse dependence.
- Confirm destructive clinical/financial actions.
- Keep critical actions visible; hide low-risk settings under secondary actions.

## Responsive
Desktop is primary for reception/lab work. Mobile focuses on collection, scanning, alerts, approvals and blood-bank field workflows.

## Accessibility
Labels, focus order, contrast, keyboard navigation and error messages must be explicit.
